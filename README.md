# 蔚蓝档案好感剧情解锁等级查询
使用方式：`python query_favor_levels.py`或者直接运行`好感剧情解锁等级查询.exe`后，输入想要查询的学生名称即可。  
------
*学生名模糊搜索依赖于 kivo.wiki 的 api 服务。  
------
`character_favor_levels.json`是`query_favor_levels.py`除 kivo.wiki 的 api 服务外唯一的运行依赖。  
`build_single_file.py`则是打包命令，打包结果是`好感剧情解锁等级查询.exe`。  
`character_favor_levels.json`中的数据按学生实装顺序更新到了狐狸小队。
